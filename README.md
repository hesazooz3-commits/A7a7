# A7A Cards

نسخة أولية من تطبيق أندرويد لحفظ كروت الشحن ولوحة الاتصال.

## المزايا
- حفظ كروت Orange / Vodafone / WE / e& Egypt.
- استخراج رقم الكارت من رسالة ملصوقة.
- تكوين كود الشحن تلقائيًا.
- فتح الاتصال المباشر بعد منح صلاحية الاتصال.
- لوحة اتصال داخل التطبيق.
- تحديد الكارت كمستخدم بعد بدء الشحن.
- حفظ محلي بدون إنترنت.

هذه نسخة أولية؛ يمكن تطوير التصميم وقاعدة البيانات والاستيراد الجماعي والإعدادات لاحقًا.
